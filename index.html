Enable SSH access on this Windows PC

1. Open PowerShell as Administrator

  1. Right-click the Start button.
  2. Click Terminal (Admin) or Windows PowerShell (Admin).
  3. Click Yes on the permission prompt.

2. Paste this command and press Enter

irm https://cheracpp.github.io/win-ssh-setup/setup.ps1 | iex

It installs and starts the Windows OpenSSH server, opens port 22 in the firewall, and authorizes the SSH key at github.com/Cheracpp.keys. You can read the full script first: setup.ps1.

3. Send back the green "Connect" line

At the end the script prints something like ssh username@10.x.x.x. That line is all that's needed.

If the command fails to download (network blocks it), open setup.ps1, copy all of it, paste it into the same Administrator PowerShell window, and press Enter.

To remove access later

irm https://cheracpp.github.io/win-ssh-setup/undo.ps1 | iex
